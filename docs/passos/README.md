# Registro de passos

Cada passo relevante do desenvolvimento ganha um arquivo `NNN-titulo-curto.md` nesta pasta, escrito no mesmo momento em que o passo é feito.

Modelo:

- **Objetivo:** o que foi feito e por quê

- **Decisões:** alternativas descartadas e motivo

- **Pendências:** o que ficou para depois
